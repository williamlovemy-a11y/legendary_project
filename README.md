


# 🏥 МедТриаж — ИИ-оценка симптомов (Локально)

Этот проект представляет собой веб-приложение для быстрой оценки симптомов пациента (триаж). Главная фишка проекта — **он работает на базе локального Искусственного Интеллекта**. Это значит, что ваши медицинские данные никуда не отправляются, а обрабатываются прямо на вашем компьютере.

Для работы нейросети мы используем программу **Ollama**. Ниже описано, как всё установить и запустить с нуля.

---

## 🛠 Шаг 1. Установка Ollama (Движок для ИИ)

**Ollama** — это программа, которая позволяет запускать мощные нейросети (похожие на ChatGPT) прямо на вашем компьютере без сложной настройки.

1. **Скачайте программу:**
   * Перейдите на официальный сайт:[https://ollama.com/](https://ollama.com/)
   * Нажмите большую кнопку **Download** и выберите вашу операционную систему (Windows, macOS или Linux).
   * Установите программу как самое обычное приложение (нажимайте "Далее" / "Next").

2. **Скачайте нейросеть (модель):**
   После установки Ollama нужно загрузить саму «базу знаний» ИИ. Мы будем использовать модель `llama3` (она весит около 4.7 ГБ, так что потребуется немного времени на скачивание).
   * Откройте **Терминал** (на Mac) или **Командную строку / PowerShell** (на Windows: нажмите `Win + R`, введите `cmd` и нажмите Enter).
   * Введите следующую команду и нажмите Enter:
     ```bash
     ollama run llama3
     ```
   * *Примечание: При первом запуске начнется скачивание. Дождитесь, пока оно дойдет до 100%. Когда в терминале появится строка для ввода сообщения (>>>), значит нейросеть успешно скачалась и работает. Можете написать "Привет" для теста, а затем закрыть терминал.*

3. **Убедитесь, что Ollama работает:**
   Убедитесь, что значок Ollama есть в трее (возле часов на компьютере). Она должна работать в фоновом режиме.

---

## 🚀 Шаг 2. Запуск проекта "МедТриаж"

Теперь, когда у нас есть локальный ИИ, запустим само веб-приложение. У вас должен быть установлен язык программирования **Python** (версии 3.8 или выше).

1. **Скачайте проект и откройте терминал в папке с проектом.**
2. **Создайте виртуальное окружение** (чтобы не засорять систему):
   ```bash
   python -m venv venv
   ```
3. **Активируйте виртуальное окружение:**
   * Для Windows:
     ```bash
     venv\Scripts\activate
     ```
   * Для macOS и Linux:
     ```bash
     source venv/bin/activate
     ```
4. **Установите нужные библиотеки** (Flask для сайта и Requests для связи с Ollama):
   ```bash
   pip install Flask requests
   ```
   *(Или `pip install -r requirements.txt`, если у вас есть этот файл)*
5. **Запустите приложение:**
   ```bash
   python app.py
   ```

---

## 🌐 Шаг 3. Использование

1. После запуска `app.py` в терминале появится ссылка, обычно это: `http://127.0.0.1:5000`
2. Откройте эту ссылку в любом браузере (Chrome, Safari, Edge).
3. Напишите свои симптомы в чат (например: "У меня сильно болит голова и температура 39").
4. Приложение отправит ваш текст в Ollama, ИИ проанализирует его, определит уровень угрозы (Красный, Желтый или Зеленый) и выдаст рекомендации!

### ❓ Возможные проблемы (FAQ)

* **Ошибка: `Connection refused` или `Ошибка подключения к локальному ИИ`**
  **Решение:** Программа Ollama не запущена. Найдите Ollama в списке установленных программ на компьютере и запустите её. Она должна висеть в фоновых процессах.
  
* **Компьютер сильно тормозит при ответе ИИ**
  **Решение:** Нейросети требуют ресурсов. При ответе используется процессор или видеокарта. Если ваш компьютер старый, ожидание ответа может занимать от 5 до 30 секунд. Если модель `llama3` слишком тяжелая, попробуйте скачать более легкую: `ollama run qwen:0.5b`, а затем в коде `app.py` поменяйте `"model": "llama3"` на `"model": "qwen:0.5b"`.
